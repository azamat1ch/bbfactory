## How to read

- **Kind:** `exec` = executable behavior (scripts/Python/adapters); `doc` = instructions/
  documentation BB must preserve or reinterpret; `caller` = obligation on the invoking
  agent rather than enforced by the upstream runner.
- **Crit (original proposal):** `crit` = initially proposed as required; `noncrit` = optional,
  cosmetic, platform-narrow, or infra-dependent — still listed so it is not silently dropped.
- **Status:** every row is `pending`. No implementation or verification has happened.
- Acceptance scenarios are *proposed* checks (fake backends / fixture files / CLI probes),
  not executed tests.
