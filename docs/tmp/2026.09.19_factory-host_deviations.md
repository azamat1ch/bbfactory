# Factory host handoff

The host fingerprint now enumerates tracked Git paths and traverses excluded dependency/build directories only where they contain tracked files. It still fingerprints new untracked files in ordinary source directories. A regular file named `env` is included. Regular-file entries also include executable permission bits, so chmod changes invalidate evidence. Enumeration failures remain incomplete snapshots.

Windows process-tree settlement returns `false` because the portable child-process path cannot verify descendants. Timeout still terminates the direct child, and the existing `processTreeSettled` result tells the caller to retain workspace ownership. No SDK or wire contract changed.

Host tests cover a real Git build file, a tracked `env` file, chmod, untracked file behavior, Unix descendant termination, and unsupported-platform fallback. `pnpm exec turbo run test --filter=bb-plugin-bbfactory -- src/host.test.ts` passed (11 tests). The full package test and typecheck were run while `service.ts` was being changed by the other worker; typecheck reported two `service.ts` argument-count errors and five service tests failed on attempt-state expectations. The integration owner should rerun the full scoped checks after that work settles.
