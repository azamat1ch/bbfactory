# Factory consolidation path map

| Previous source | Destination |
| --- | --- |
| plugins/factory-team/server.ts, shared.ts, app.tsx, app.css, app.test.tsx, server.test.ts, env.d.ts | plugins/factory/team/ with the same basename |
| plugins/factory-team/factory-server.ts, factory-server.test.ts, factory-host.ts, factory-app.tsx | plugins/factory/ with the same basename |
| plugins/factory-team/package.json, tsconfig.json, vitest.config.ts, README.md | plugins/factory/ with the same basename |

| plugins/factory-guidance/server.ts, review.ts, tests, legal/provenance and skills | plugins/factory/review/ with relative paths retained |
| plugins/factory-team/skills/team | plugins/factory/review/legacy-team-skill |

Removed redundant task/guidance package manifests and configs, and cross-plugin
skill staging script. The sole Factory workspace package keeps the name
`bb-plugin-factory-team`, preserving installation/storage identity. Bundled source
registration resolves directory `factory`, with compatibility ID `factory-team`.
Devin's maintained operational guidance belongs in `plugins/factory/skills/factory`.

Task execution seam changes are in tasks/service.ts and tasks/server.ts. The
third argument injects internal execution handlers; old tests can still construct
standalone task service fixtures. The composed product always injects handlers.
