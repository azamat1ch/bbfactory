- Storage migration is positional and hash-checked. Preserved the Team/task
  prefix and compatibility ID `factory-team`; appended execution and legacy
  ownership tables. Source package directory is now `plugins/factory`.
- Legacy runs retain their original owner/database. The read-only peer-store
  guard requires a conservative whole-owner drain, including uncertain spawn
  attempts, before new runs use the other owner. Upgrades retain saved standalone
  enablement; disable/removal is blocked until settled. No automatic mid-run
  disable, data reset, or active-run copying occurs.

  existing task assignments. Missing legacy DB/run is unresolved, never replayed
  into the new store. Settled legacy inspection survives standalone disable.
- Execution source is vendored from Workflows, with standalone source retained.
  Shared bug fixes require both modules; see execution/PROVENANCE.md. No new
  scheduler, pipeline, review-depth engine or resource queue was introduced.

  remains an explicit compatibility RPC to its owner; legacy steering/waiting
  stays on standalone surfaces until drain.
