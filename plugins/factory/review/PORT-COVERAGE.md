## Dependencies and deliberate divergences

- Workflows experimental execution start/inspect/cancel/guide RPCs and Factory
  task/action tools are sibling integration work. Their conformance tests must be
  linked after integration; this branch does not award runtime coverage for them.
- Team selection remains the existing Auto/Off/Selected picker. Historical
  profile catalogs, default rankings, shell globs and environment overrides are
  adapted to native discovery/preferences, not silently asserted equivalent.
- Generic workflow examples inherit origin permissions; assignment-specific
  environments/access require the new execution seam. No portable read-only
  confinement or detached-process stop guarantee is inferred.
- Workflows now provides cursor-based first-completion waits and durable guidance
  receipt deduplication, tested in `plugins/workflows/src/service-policy.test.ts`.
  These are native adaptations, not full Porch mailbox/acknowledgement parity.
  Provider continuation leases, diagnostic redaction and twelve-store
  history/analytics remain gaps.
- Review plans are fully specified guidance (including super 9-pass and ultra
  20-pass ordering), not an automatic launcher. Judge fallback selection/launch,
  input snapshot freshness and omitted-roster detection remain caller duties.
- Collector source quotes require exact normalized equality, stricter than the
  upstream substring heuristic. Missing snapshots yield unknown, never true.
  Collector output remains untrusted review evidence, never task acceptance.
- Platforms and provider semantics require their own tested support matrix.
  Source text preservation tests prove assets, not agent compliance.
